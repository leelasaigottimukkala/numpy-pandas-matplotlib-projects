# Student Performance Analysis using Matplotlib

## 📌 Project Overview
This project analyzes student academic performance using Python.  
It focuses on calculating performance metrics and visualizing insights using **Matplotlib**, with data handling done using **Pandas** and **NumPy**.

---

## 📊 Dataset Description
The dataset contains academic and attendance details of students:

- Student_ID
- Math marks
- Science marks
- English marks
- Attendance percentage

---

## 🛠 Tools & Libraries Used
- Python
- NumPy
- Pandas
- Matplotlib

---

## 🔍 Analysis Performed
- Calculated average marks for each student
- Categorized student performance as *Good*, *Average*, or *Poor*
- Analyzed subject-wise average scores
- Studied the relationship between attendance and academic performance

---

## 📈 Visualizations
The following visualizations were created using Matplotlib:
- Bar chart for subject-wise average marks
- Scatter plot showing attendance vs average marks
- Histogram of average marks distribution
- Bar chart of performance category counts

---

## ✅ Key Insights
- Students with higher attendance generally perform better academically
- Math and Science have higher average scores compared to English
- Majority of students fall under the *Good* and *Average* performance categories

This project demonstrates:
- Data preprocessing and feature engineering
- Exploratory data analysis using Matplotlib
- Ability to extract and communicate insights from academic data
